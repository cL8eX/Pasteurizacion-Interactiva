PFD Design - Etapa 1: separar biblioteca PFD

Base: Beta 3.0 + biblioteca PFD funcional que el usuario verifico visualmente.

Cambios:
- index.html: ahora enlaza pfd-library.css y pfd-library.js.
- pfd-library.css: estilos exclusivos de la biblioteca de simbolos PFD.
- pfd-library.js: datos SVG, filtros, busqueda, seleccion y panel de vista previa.

No se modifico supabase-config.js, README.txt ni SQL_CREAR_PROYECTOS.sql.
Esta base beta3 no contiene archivos script.js ni styles.css separados; el codigo principal de la aplicacion permanece dentro de index.html. Para evitar reconstruir o reubicar el codigo preexistente, se crearon archivos exclusivos pfd-library.* para el modulo PFD.

Para actualizar el repositorio, copiar unicamente index.html, pfd-library.css y pfd-library.js. No reemplazar otros archivos ni la carpeta .git.
