PFD Design - Etapa 1: Biblioteca ampliada de símbolos

Base: Pasteurizacion-Interactiva_beta3_PFD_Etapa1_Interfaz.zip (la base que el usuario confirmó como la última subida a GitHub).

Cambios en esta actualización:
- Se amplió la biblioteca a un catálogo grande de símbolos PFD, con nombres en español.
- Categorías dinámicas: Equipos, Válvulas, Instrumentación, Corrientes, Accesorios y otros.
- Búsqueda por nombre, descripción o categoría.
- Iconografía con colores por categoría y una vista de detalle/selección.
- Se mantiene el lienzo vacío; no se implementó inserción ni conexión de símbolos.

Archivos modificados: pfd-library.js y pfd-library.css. Se conserva el resto de la aplicación y configuración.


ETAPA 2 - DIAGRAMA PFD EDITABLE
- Se recreó el PFD de pasteurización con elementos SVG individuales.
- Selecciona un elemento para editar su etiqueta desde el panel derecho.
- Arrastra elementos para reubicarlos.
- Inserta símbolos desde la biblioteca lateral.
- El estado se guarda localmente por proyecto en este navegador.
- Usa Restaurar para volver a la disposición inicial.


ETAPA 3 - COLOR Y ORDEN DEL PFD
- Símbolos con colores por categoría: bombas azul, tanques verde/teal, intercambiadores naranja, pasteurizadores rojo, homogeneizadores morado, válvulas ámbar, instrumentos morado.
- Diagrama reordenado en bandas de proceso para reducir cruces y superposición.
- Tuberías con rutas ortogonales y flechas.
- Se cambió la clave de guardado local a v3 para que el navegador cargue la nueva distribución inicial y no reutilice el layout anterior.
- Se versionó pfd-library.js para evitar caché.
