PFD Design - Etapa 1: Biblioteca ampliada de símbolos

Base: Pasteurizacion-Interactiva_beta3_PFD_Etapa1_Interfaz.zip (la base que el usuario confirmó como la última subida a GitHub).

Cambios en esta actualización:
- Se amplió la biblioteca a un catálogo grande de símbolos PFD, con nombres en español.
- Categorías dinámicas: Equipos, Válvulas, Instrumentación, Corrientes, Accesorios y otros.
- Búsqueda por nombre, descripción o categoría.
- Iconografía con colores por categoría y una vista de detalle/selección.
- Se mantiene el lienzo vacío; no se implementó inserción ni conexión de símbolos.

Archivos modificados: pfd-library.js y pfd-library.css. Se conserva el resto de la aplicación y configuración.


ETAPA 4 - PFD COLOR Y ORDEN
- Se conservó el HTML principal completo de la aplicación.
- El PFD se organiza en cuatro bandas de proceso y una columna de precalentamiento.
- Simbología a color por categoría; tuberías y señales diferenciadas.
- El editor usa almacenamiento local pfd-editable-v5 para no recuperar diagramas anteriores.

ETAPA 5 - ORGANIZACION VISUAL
- Diagrama distribuido en cuatro bandas con separación entre procesos.
- Flujo principal, circuito de precalentamiento y pasteurización final separados visualmente.
- Nueva clave local pfd-editable-v6 para evitar recuperar posiciones anteriores.
- Archivos CSS/JS con versión de caché v5.

ETAPA 6 - PANEL DERECHO PFD
El panel derecho ahora permite editar los atributos del elemento seleccionado:
texto principal, descripción/parámetros, familia, código de equipo, forma y color.
La tabla de nomenclatura vinculada permite seleccionar directamente un elemento del diagrama.
Al aplicar, se guarda la edición en el proyecto y se actualiza el símbolo. La clave local cambia a v7.

ETAPA 8 - ACCIONES SUPERIORES DEL EDITOR PFD
- Se agregó botón Volver al Inicio.
- Se agregó Pantalla completa para el editor PFD.
- Se agregó Descargar PDF: abre una vista de impresión A3 horizontal con el SVG y nomenclatura, desde donde se puede guardar como PDF.
- Se agregó Guardar: guarda el estado del diagrama PFD en el almacenamiento local del navegador.
- Se actualizó cache busting a v8.
