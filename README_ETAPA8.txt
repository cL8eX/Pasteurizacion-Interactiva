PFD Design - Etapa 8

Acciones en la cabecera del editor PFD:
- Inicio: vuelve al dashboard del proyecto.
- Pantalla completa: amplía el editor PFD al área de pantalla completa; Escape para salir.
- Descargar PDF: abre una ventana de impresión con el PFD en formato A3 horizontal y la tabla de nomenclatura. Selecciona "Guardar como PDF" en el diálogo de impresión.
- Guardar: guarda el diagrama PFD en localStorage para este proyecto y muestra confirmación.

Archivos modificados:
- index.html: referencias con versión 8.
- pfd-library.js: acciones de cabecera, fullscreen, exportación PDF y guardado local.
- pfd-library.css: estilos de botones y cabecera.
